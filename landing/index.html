Will it run on
my device?

Screen Recorder runs on 64-bit Windows, Mac and Linux computers, and on Android phones and tablets. Check yours below before you download.

Windows

  • Windows 11, or Windows 10 version 1809 or newer
  • 64-bit (x64). Also runs on Windows 11 on ARM
  • File: ScreenRecorder-Setup.exe

Mac

  • macOS 10.15 Catalina or newer, including macOS 15 Sequoia and later
  • Apple Silicon (M1–M4) and Intel
  • File: ScreenRecorder-macOS.dmg

Linux

  • Ubuntu 24.04+, Debian 13+: the .deb
  • Ubuntu 22.04, Debian 12, Mint 21+, Fedora 38+ and most others: the AppImage
  • 64-bit (x86_64). Live effects and auto-zoom need an X11 session

Android

  • Android 10 or newer, phones and tablets
  • Records the screen and sound, saves to your Gallery
  • File: ScreenRecorder-Android.apk (32-bit version for older phones)
Not supported
  • 32-bit computers (any system). The app is built with Flutter, which only makes 64-bit desktop apps.
  • Windows 7, 8 and 8.1, and Windows 10 before version 1809
  • macOS 10.14 Mojave and older
  • Linux on ARM (Raspberry Pi and similar), and Linux older than Ubuntu 22.04 / Debian 12
  • iPhone and iPad, Android 9 and older, and Chromebooks

Not sure? On Windows, open Settings → System → About and look for “64-bit operating system”. On a Mac, open Apple menu → About This Mac. On Linux, run uname -m: you need x86_64. On Android, open Settings → About phone for the Android version.
